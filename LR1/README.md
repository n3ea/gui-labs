## Задание

 Сделать окно, кнопку и надпись. При нажатии кнопки надпись меняется на изображение.

---

## Описание работы

Функционал:

- Главное окно с заголовком «Лабораторная работа №1».
- Надпись (`QLabel`) с текстом по центру.
- Кнопка (`QPushButton`) «Показать изображение».
- При нажатии кнопки:
  1. Открывается диалог выбора файла (`QFileDialog`).
  2. Пользователь выбирает изображение.
  3. Надпись заменяется на выбранное изображение.
- При изменении размера окна изображение перемасштабируется с сохранением пропорций.
- При попытке загрузить некорректный файл выводится сообщение об ошибке (`QMessageBox`).

- Python 3.6+
- PyQt5
